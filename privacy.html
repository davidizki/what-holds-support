Privacy policy

Effective 12 August 2026. What Holds works without an account. The developer does not sell data, use it for advertising, track you across apps or websites, or operate a cloud copy of your library.

Data stored on your device

Captured sources, notes, claims, review cards, review history, preferences, and search data are kept in the app’s private storage on your device. The share extension uses that same private storage only to hand something you selected to the main app.

Apple’s on-device Foundation Model can create notes and compare Fact-check claims with retrieved evidence on your device. For Fact-check it creates readable claims grounded in exact raw source wording; both that raw wording and the complete acquired source remain available to you. What Holds also checks summaries against the source, can repair a weak section from the closest source passage, and uses built-in methods for longer sources or whenever Apple Intelligence is unavailable. It does not send prompts or results from these methods to the developer. Ask searches the local library without calling a model service.

On supported system-26 devices, Apple SpeechAnalyzer and SpeechTranscriber process imported or publisher-provided audio on device. The transcriber modules do not send the voice audio to Apple servers. The system may contact Apple to check for or install the selected language asset.

Fact-check has an Apple-first default and an optional broader route

Automatic keeps the full source on device and sends only the bounded research concepts described above to English Wikipedia, Crossref, and, for biomedical topics, Europe PMC. What Holds stores the relevance-filtered title, URL, and excerpt locally. Apple Intelligence creates a readable claim grounded in exact raw wording and compares at most three relevant excerpts on device when ready; the app’s built-in scan takes over otherwise and leaves references unresolved rather than treating topical overlap as proof. Request handling is governed by the Wikimedia Foundation Privacy Policy, Crossref Privacy Policy, and the EMBL-EBI privacy notice for Europe PMC.

Broader LLM web research begins only after you save an OpenAI Platform API key and approve a clear explanation of what will be sent to OpenAI. The request goes to OpenAI’s Responses API, asks OpenAI not to store the response, and uses live web search. OpenAI and the websites it searches may receive normal request and connection information under their own terms and privacy policies; OpenAI API charges apply. This feature does not connect to a ChatGPT account or subscription. The key is stored separately in Apple Keychain from any custom-model token. Every Fact-check option is automated and incomplete, and finding no result does not prove a claim false.

Custom model endpoints are an advanced override

Custom model processing is not required and does not connect to a ChatGPT subscription. It begins only after you enable a service in Advanced settings and approve a clear explanation that the source and any saved API token will be sent there. Remote endpoints must use HTTPS; plain HTTP is accepted only for localhost or a private local-network server. Login details and extra URL parameters are rejected in the service address. Changing the address clears the saved token and requires new consent. The service operator—not What Holds—controls its retention, logging, training, security, and deletion practices. Review that provider’s policy before enabling it. A local service can keep the model running on hardware you control.

Endpoint credentials are stored in Apple Keychain and are excluded from library exports, shared notes, screenshots, and the public support site. Disable the endpoint to stop future requests; contact its operator about any data it already received.

Source retrieval is not background collection

Article, caption, feed, transcript, and audio requests happen because you selected that source. Public HTTP links are upgraded to HTTPS before any request; a site that works only over plain HTTP is rejected. If the first page contains no article text, What Holds may briefly render the same secure page for no more than 15 seconds without keeping cookies or website data. The selected site and the services it uses still receive normal browser requests. The app does not bypass a login, paywall, CAPTCHA, anti-bot system, or publisher restriction. YouTube capture retrieves caption text only and does not download the video or audio. Publisher audio is held in a temporary file only for on-device transcription and is removed after success, failure, or cancellation.

Retention, export, and deletion

Local library data remains until you delete an item, erase the library in Settings, or remove the app, subject to Apple platform backup behavior. Deleting a note also removes its source, claims, cards, and review history when they are no longer used elsewhere. Temporary publisher-audio downloads are removed after the app finishes trying to retrieve them and are not part of the library or its backup.

You can export a JSON backup or share an individual note as Markdown. Those files are then controlled by the location or service you choose. What Holds has no user account or server copy of your library to delete on your behalf.

This website and support

This static site is hosted by GitHub Pages. The developer has not added advertising or analytics. GitHub may process connection information under the GitHub General Privacy Statement.

The current support route uses public GitHub issues. It requires a GitHub account, and the issue text is visible publicly. Do not include captured content, personal data, API tokens, credentials, or anything you do not want published. GitHub governs account and issue data under its own policy.
