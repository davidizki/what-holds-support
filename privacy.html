Privacy policy

Effective 12 August 2026. What Holds works without an account. The developer does not sell data, use it for advertising, track you across apps or websites, or operate a cloud copy of your library.

Data stored on your device

Captured sources, knowledge notes, claims, review cards, review history, preferences, and local search data are stored in the app container. Share extensions use the app’s private shared container only to hand selected content to the main app.

Apple on-device Foundation Model processing, local source-grounding checks and bounded passage repair for Summary, extractive processing for longer eligible sources, and the deterministic engine run on the device. What Holds does not send their prompts or results to the developer. Ask is also an extractive search over the local library and does not call a model service.

On supported system-26 devices, Apple SpeechAnalyzer and SpeechTranscriber process imported or publisher-provided audio on device. The transcriber modules do not send the voice audio to Apple servers. The system may contact Apple to check for or install the selected language asset.

When information leaves the device

What Holds makes no background analytics or advertising requests. Network activity occurs only for an action you select or a processing route the app identifies before it runs.

Fact-check is a public evidence lookup

The English Wikipedia API receives the short claim query described above. What Holds stores the returned page title, URL, and excerpt locally with the note. Wikimedia’s handling of requests is governed by the Wikimedia Foundation Privacy Policy. The scan is preliminary, not exhaustive, and an absent result is not proof that a claim is false.

Custom model endpoints are an advanced override

Custom model processing is not required and is not a connection to a ChatGPT subscription. It begins only after you enable an endpoint in Advanced settings with a clear disclosure that the acquired source and any saved API token used as an authorization credential will be sent there. Changing the destination clears the saved token and requires new consent. The endpoint’s own operator—not What Holds—controls its retention, logging, training, security, and deletion practices. Review that provider’s policy before enabling it. A local endpoint can keep inference on hardware you control.

Endpoint credentials are stored in Apple Keychain and are excluded from library exports, shared notes, screenshots, and the public support site. Disable the endpoint to stop future requests; contact its operator about any data it already received.

Source retrieval is not background collection

Article, caption, feed, transcript, and audio requests happen because you selected that source. Public HTTP links and discovered resources are upgraded to HTTPS before any request; an HTTP-only host is rejected rather than weakening App Transport Security. If ordinary article extraction finds only an app shell, What Holds may render that same secure public URL once in a non-persistent WebKit session for no more than 15 seconds. The selected site and its embedded-resource hosts receive normal browser requests, but the app does not retain WebKit cookies or website data. Rendering does not bypass sign-in, paywall, CAPTCHA, anti-bot, or publisher restrictions. YouTube acquisition retrieves caption text only and does not download the video or audio. A publisher audio response is held in a temporary file only for on-device transcription and is removed after success, failure, or cancellation.

Retention, export, and deletion

Local library data remains until you delete an item, erase the library in Settings, or remove the app, subject to Apple platform backup behavior. Deleting a note also removes its app-managed source, claims, cards, and review history when they are no longer used elsewhere. Temporary publisher-audio downloads are removed after the acquisition attempt and are not part of the library or its backup.

You can export a versioned JSON backup or share an individual note as Markdown. Those files are then controlled by the location or service you choose. What Holds has no developer account or server-side library to delete on your behalf.

This website and support

This static site is hosted by GitHub Pages. The developer has not added advertising or analytics. GitHub may process connection information under the GitHub General Privacy Statement.

The current support route uses public GitHub issues. It requires a GitHub account, and the issue text is visible publicly. Do not include captured content, personal data, API tokens, credentials, or anything you do not want published. GitHub governs account and issue data under its own policy.
