Understand how a note was made

Automatic processing needs no setup. Before saving, the app shows what it expects to use. Afterwards, the note shows what actually made it.

On-device intelligence ready
Apple’s Foundation Model is available, supports the language, and can be used automatically for every eligible mode. Fact-check asks it to reason over retrieved evidence excerpts; Copy uses it only for tags and its review card, while the Copy body remains exact.
Turn on Apple Intelligence for richer processing
On iPhone or iPad, open Settings; on Mac, open System Settings. Then choose Apple Intelligence & Siri. What Holds already works with its private built-in processing, so enabling this is optional.
Apple Intelligence is getting ready
Apple Intelligence may still be downloading. Keep the device powered and connected as appropriate, then use Check again. What Holds continues with its built-in processing in the meantime.
Standard processing is ready
The operating system, hardware, region, or language is not eligible. No action is required; the standard built-in option remains available.
Compatibility: What Holds supports iOS/iPadOS 17 or later and macOS 14 or later. Apple’s on-device generation requires additional Apple Intelligence eligibility and iOS/iPadOS/macOS 26 or later.

Capture help

A link will not load

Only public web links are accepted. What Holds uses a secure HTTPS connection and rejects a site that works only over plain HTTP. It first reads the normal page; if the article loads later, the app can briefly open the same page without keeping its cookies or website data. The website still receives the normal requests needed to display it. Paywalls, login screens, CAPTCHAs, anti-bot systems, unsupported scripts, or the publisher’s own restrictions can prevent access; the app does not bypass them. Paste text or import a supported file when you have the right to do so.

A YouTube video has no usable transcript

What Holds uses available public caption text and never downloads YouTube video or audio. If the creator disabled captions, the selected language is unavailable, or YouTube does not return usable captions, the app stops without guessing from the title or page footer. In YouTube, open Show transcript, copy the transcript when available, and capture it as Text. Use the Audio & caption language control when you need a specific available caption track.

A podcast or audio link does not transcribe

The app prefers a publisher or Podcasting 2.0 transcript. Otherwise it can follow a publisher-provided audio link and transcribe supported audio on device on system version 26 or later. Audio may be up to 250 MB. Keep the device connected while any required Apple language assets install, choose the spoken language when automatic detection is wrong, and retry. Publisher restrictions or unsupported audio can still prevent access.

A file is rejected

Supported documents are PDF, plain text, Markdown, HTML, and RTF, up to 30 MB. Supported audio files use the system audio decoder and may be up to 250 MB on system version 26 or later. Image-only scans need selectable text before What Holds can process them.

The note looks incomplete

What Holds should show an error instead of quietly saving a title, page controls, or other incomplete text. In the saved note, check where the source came from and how the note was made, then choose View acquired source to inspect the complete stored text. Older YouTube captures that contain only page controls show a recapture warning. Try pasting some text directly to find out whether the problem is reading the source or making the note.

The share extension queued an item

Open What Holds and check Inbox. The extension hands the item to the main app; the capture is processed only after you choose its treatment.

Backup, move, and delete a library

The first release keeps a separate local library on each device and does not promise sync.

  1. Open Settings in What Holds.
  2. Choose Export library and save the JSON file somewhere you control.
  3. On another installation, choose Import and merge and select that file.

Delete an individual note from its detail menu. To erase the local archive, choose Erase local library in Settings after exporting anything you may want to keep. Uninstalling the app removes app-container data, subject to Apple platform backup behavior.

Know what Fact-check can and cannot establish

The default is Automatic Apple-first Fact-check. Apple Intelligence turns noisy source captions into readable claims while What Holds keeps the matching raw wording available under Captured wording. Instead of searching the first words of a caption, the app plans a small set of relevant research concepts and searches English Wikipedia, cross-domain scholarly abstracts from Crossref, and biomedical literature from Europe PMC when appropriate. Several candidates are checked for the same subject and outcome before Apple reasons over the evidence on your device. Otherwise the Public evidence scan shows relevant references without treating word overlap as proof.

For a wider search of current web sources, expand Broader Fact-check research · Optional in Settings, enter an OpenAI model and OpenAI Platform API key, save the key, then review and accept the disclosure. An OpenAI reasoning model can then search live sources and return links that What Holds checks against the search response. OpenAI bills API usage separately, and a ChatGPT subscription cannot be used instead. The app stores the key separately in Apple Keychain and asks OpenAI not to store the response.

Unsupported means the selected method did not find enough supporting evidence. It does not prove the claim false. Every option is an automated research aid—not exhaustive research or professional verification—so open the links and consult relevant primary or specialist sources before an important decision.

Use a custom model endpoint only when you intend to

The Advanced settings accept an OpenAI-compatible web address, model name, and optional API token. Remote services must use HTTPS; plain HTTP is accepted only for localhost or a private local-network server. Login details and extra URL parameters do not belong in the address. The separate token is sent only to the service you chose; changing that address clears the token and asks for consent again. Enabling this option replaces automatic Apple and built-in processing for Concept, Summary, Analysis, and Copy. Fact-check remains Apple-first unless you separately enable broader research.

  • The full acquired title, URL, source text, and processing instructions go to the configured endpoint.
  • The token is stored in Apple Keychain and is not included in a library export.
  • A ChatGPT subscription is not an API key and cannot be connected as an account.
  • A local server such as Ollama can keep the model running on hardware you control.
  • For a remote provider, paste its HTTPS base URL and put its bearer token only in the separate API token field.
  • On a physical iPhone, localhost means the iPhone—not your Mac. A Mac-hosted endpoint requires an intentionally exposed and secured network address.

If the endpoint reports an error, What Holds shows it rather than silently sending the source somewhere else. Disable the override to return to automatic private processing.

For Apple App Review

No demo account, login, subscription, API token, or external model is required to exercise the core product. On Simulator and devices where Apple Intelligence is unavailable, standard built-in processing is expected.

  1. Choose Start learning on first launch.
  2. Create a Text capture with at least eight words and choose Summary.
  3. Process and save, then open the note in Library to see where the source came from and how the note was made; choose View acquired source to confirm the exact stored text.
  4. Open Review to reveal and rate a card.
  5. Open Ask and search the local library; every result links back to its supporting note.

Fresh installs use Automatic Fact-check. On Simulator, the visibly labelled Public evidence scan retrieves bounded public reference and scholarly evidence but leaves it unresolved without a language model; on an eligible device Apple Intelligence creates readable source-grounded claims and reasons over the relevant excerpts on device. No key is required. Broader OpenAI research and custom models are optional and are not needed for review.
