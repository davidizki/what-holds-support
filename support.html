Understand the processing status

Automatic processing needs no setup. The capture screen shows the expected route, and the saved note shows the route that actually completed the work.

On-device intelligence ready
Apple’s Foundation Model is available, supports the language, and can be used automatically for eligible Concept, Summary, Analysis, and Copy metadata work. The Copy body remains exact.
Turn on Apple Intelligence for richer processing
On iPhone or iPad, open Settings; on Mac, open System Settings. Then choose Apple Intelligence & Siri. What Holds already works through its private deterministic engine, so enabling this is optional.
Apple Intelligence is getting ready
The system model may still be downloading. Keep the device powered and connected as appropriate, then use Check again. Captures continue through the deterministic fallback meanwhile.
Standard processing is ready
The operating system, hardware, region, or language is not eligible. No action is required; the built-in deterministic route remains available.
Compatibility: What Holds supports iOS/iPadOS 17 or later and macOS 14 or later. Apple’s on-device generation requires additional Apple Intelligence eligibility and iOS/iPadOS/macOS 26 or later.

Capture help

A link will not load

Only public HTTP and HTTPS pages are supported. What Holds first reads the ordinary page response. If that is only an app shell, it makes one bounded attempt to render the same page on device without retaining cookies or website data. The site and its embedded-resource hosts still receive ordinary page requests. Paywalls, sign-in walls, CAPTCHAs, anti-bot systems, unsupported scripts, or a site’s own restrictions can still prevent extraction; the app does not bypass them. Paste text or import a supported file when you have the right to do so.

A YouTube video has no usable transcript

What Holds uses available public caption text and never downloads YouTube video or audio. If the creator disabled captions, the selected language is unavailable, or YouTube does not return usable captions, the app stops without guessing from the title or page footer. In YouTube, open Show transcript, copy the transcript when available, and capture it as Text. Use the Audio & caption language control when you need a specific available caption track.

A podcast or audio link does not transcribe

The app prefers a publisher or Podcasting 2.0 transcript. Otherwise it can follow a publisher-provided audio link and transcribe supported audio on device on system version 26 or later. Audio may be up to 250 MB. Keep the device connected while any required Apple language assets install, choose the spoken language when automatic detection is wrong, and retry. Publisher restrictions or unsupported audio can still prevent acquisition.

A file is rejected

Supported documents are PDF, plain text, Markdown, HTML, and RTF, up to 30 MB. Supported audio files use the system audio decoder and may be up to 250 MB on system version 26 or later. Image-only scans need selectable text before What Holds can process them.

The note looks incomplete

What Holds should show an error instead of silently saving title text, controls, or another empty/partial acquisition. In the saved note, compare the separate acquisition and processing labels, then choose View acquired source to inspect the complete stored input. Older YouTube captures that contain only page controls show a recapture warning. Try a pasted-text capture to separate source-access problems from processing problems.

The share extension queued an item

Open What Holds and check Inbox. The extension hands the item to the main app; the capture is processed only after you choose its treatment.

Backup, move, and delete a library

The first release keeps a separate local library on each device and does not promise sync.

  1. Open Settings in What Holds.
  2. Choose Export library and save the JSON file somewhere you control.
  3. On another installation, choose Import and merge and select that file.

Delete an individual note from its detail menu. To erase the local archive, choose Erase local library in Settings after exporting anything you may want to keep. Uninstalling the app removes app-container data, subject to Apple platform backup behavior.

Know what Fact-check can and cannot establish

Fact-check sends a short query derived from selected claim text to the public English Wikipedia API, then compares the returned introductory extract with the claim. This is a preliminary automated evidence scan—not exhaustive research, a professional fact-check, or a universal truth score.

Unsupported means the scan did not find corroboration. It does not prove the claim false. Follow the attached evidence link and consult specialist or primary sources before relying on an important conclusion.

Use a custom model endpoint only when you intend to

The Advanced processing controls accept an OpenAI-compatible base URL, model identifier, and optional API token. The token is sent only to that destination as an authorization credential; changing the destination clears it and requires new consent. Enabling this route overrides automatic Apple/deterministic processing for eligible modes. Fact-check never uses it as evidence.

  • The full acquired title, URL, source text, and processing instructions go to the configured endpoint.
  • The token is stored in Apple Keychain and is not included in a library export.
  • A ChatGPT subscription is not an API credential and cannot be connected as an account.
  • A local server such as Ollama can keep inference on hardware you control.
  • On a physical iPhone, localhost means the iPhone—not your Mac. A Mac-hosted endpoint requires an intentionally exposed and secured network address.

If the endpoint reports an error, What Holds shows it rather than silently sending the source somewhere else. Disable the override to return to automatic private processing.

For Apple App Review

No demo account, sign-in, subscription, API token, or external model is required to exercise the core product. On Simulator and devices where Apple’s model is unavailable, the deterministic fallback is the expected route.

  1. Choose Start learning on first launch.
  2. Create a Text capture with at least eight words and choose Summary.
  3. Process and save, then open the note in Library to inspect the separate source-acquisition and processing provenance; choose View acquired source to confirm the exact stored input.
  4. Open Review to reveal and rate a card.
  5. Open Ask and search the local library; every result links back to its supporting note.

Fact-check intentionally contacts Wikipedia. The custom endpoint remains an optional Advanced feature and is not needed for review.
