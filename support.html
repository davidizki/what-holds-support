Understand how a note was made

Automatic processing needs no setup. Before saving, the app shows what it expects to use. Afterwards, the note shows what actually made it.

On-device intelligence ready
Apple’s Foundation Model is available and supports the language. It is used automatically for every intelligent stage, including long-source section processing, Fact-check claim selection, and evidence reasoning. Copy keeps its canonical body byte-exact and may add a word-identical readable view.
Turn on Apple Intelligence for richer processing
On iPhone or iPad, open Settings; on Mac, open System Settings. Then choose Apple Intelligence & Siri. What Holds already works with its private built-in processing, so enabling this is optional.
Apple Intelligence is getting ready
Apple Intelligence may still be downloading. Keep the device powered and connected as appropriate, then use Check again. What Holds continues with its built-in processing in the meantime.
Standard processing is ready
The operating system, hardware, region, or language is not eligible. No action is required; the standard built-in option remains available.
Compatibility: What Holds supports iOS/iPadOS 17 or later and macOS 14 or later. Apple’s on-device generation requires additional Apple Intelligence eligibility and iOS/iPadOS/macOS 26 or later.

Choose what the source should do for you

The five treatments and the learning goal answer different questions. Concept, Summary, Fact-check, Analysis, or Copy decides the shape of the saved result. Find later, Understand, Recall, Use it, or Keep current decides what happens afterwards.

Find later
Keeps Concept, Summary, or Analysis searchable without adding memory work. Copy always uses this path because an arbitrary source sentence is not automatically worth memorising.
Understand or Recall
Creates the smallest grounded practice plan after processing. Summary asks you to reconstruct all key points rather than recognise one opening phrase. The first practice begins the following day.
Use it
Asks where you expect to need the idea and uses that situation in the practice prompt. This rehearses application instead of treating definition recall as proof that knowledge will transfer.
Keep current
Fact-check uses a separate evidence queue. Choose how quickly the subject can change: mostly stable starts at 365 days, changes sometimes at 90, and changes quickly at 30. These are visible defaults, not a guarantee of optimal timing.

Why the app asks what you think first

For learning goals, you can write one quick prediction before processing. It is optional and does not need to be correct. The finished note keeps it visible so you can compare your starting model with what the grounded result actually says.

How memory review works

Confidence before reveal is required so the app records what you believed before feedback changes your judgment.

  1. Try the answer before revealing it. Type it, or answer aloud and leave the field blank.
  2. Choose Unsure, Somewhat sure, or Sure before seeing feedback.
  3. Reveal the source-grounded answer and compare your attempt as Missed, Partial, Solid, or Effortless.
  4. If you were Sure but Missed or were Partial, state what changed in your own words before continuing.

The next interval responds mainly to performance, with modest adjustments for confidence and the horizon you chose. The schedule is an evidence-informed product heuristic, not a universal prediction of what you remember.

How evidence review works

A due claim keeps its captured wording, old verdict, explanation, and citations together. Choose Re-run evidence check to repeat the full research flow and replace the Fact-check in place, or open and check the cited sources yourself before scheduling the next review. Rerunning preserves the note’s identity, favourite state, and relationships; it does not create a duplicate. Older captures marked Reprocess recommended stay out of active review until you update them from their exact stored source.

Capture help

A link will not load

Only public web links are accepted. What Holds uses a secure HTTPS connection and rejects a site that works only over plain HTTP. It first reads the normal page; if the article loads later, the app can briefly open the same page without keeping its cookies or website data. The website still receives the normal requests needed to display it. Paywalls, login screens, CAPTCHAs, anti-bot systems, unsupported scripts, or the publisher’s own restrictions can prevent access; the app does not bypass them. Paste text or import a supported file when you have the right to do so.

A YouTube video has no usable transcript

What Holds uses available public caption text and never downloads YouTube video or audio. If the creator disabled captions, the selected language is unavailable, or YouTube does not return usable captions, the app stops without guessing from the title or page footer. In YouTube, open Show transcript, copy the transcript when available, and capture it as Text. Use the Audio & caption language control when you need a specific available caption track.

A podcast or audio link does not transcribe

The app prefers a publisher or Podcasting 2.0 transcript. Otherwise it can follow a publisher-provided audio link and transcribe supported audio on device on system version 26 or later. Audio may be up to 250 MB. Keep the device connected while any required Apple language assets install, choose the spoken language when automatic detection is wrong, and retry. Publisher restrictions or unsupported audio can still prevent access.

A file is rejected

Supported documents are PDF, plain text, Markdown, HTML, and RTF, up to 30 MB. Supported audio files use the system audio decoder and may be up to 250 MB on system version 26 or later. Image-only scans need selectable text before What Holds can process them.

The note looks incomplete

What Holds should show an error instead of quietly saving a title, page controls, or other incomplete text. In the saved note, check where the source came from and how the note was made, then choose View acquired source to inspect the complete stored text. Older YouTube captures that contain only page controls show a recapture warning. Try pasting some text directly to find out whether the problem is reading the source or making the note.

Apple Intelligence could not finish

An available Apple model gets one bounded fresh retry or focused output repair. If the result still cannot be grounded safely, What Holds keeps the acquired source in the capture sheet and saves no note. Choose Try again, explicitly choose Use Standard processing instead for that capture, or cancel. Standard processing starts automatically only when Apple Intelligence was unavailable before processing.

The share extension queued an item

Open What Holds and check Inbox. The extension hands the item to the main app; the capture is processed only after you choose its treatment.

Backup, move, and delete a library

The first release keeps a separate local library on each device and does not promise sync.

  1. Open Settings in What Holds.
  2. Choose Export library and save the JSON file somewhere you control.
  3. On another installation, choose Import and merge and select that file.

Delete an individual note from its detail menu. To erase the local archive, choose Erase local library in Settings after exporting anything you may want to keep. Uninstalling the app removes app-container data, subject to Apple platform backup behavior.

Know what Fact-check can and cannot establish

The default is Automatic Apple-first Fact-check. Apple inventories every ordered source section and selects one to five material, independently verifiable propositions. Advice, slogans, promotions, subjective judgements, and incomplete caption fragments are left out instead of padded into a quota. Every clean claim keeps its exact raw wording under Captured wording.

What Holds sends at most 12 short source-grounded research words to English Wikipedia and Wikidata, Crossref and OpenAlex, and relevant PubMed and Europe PMC records. Before Apple sees a reference, the app requires it to address both the claim’s subject and decisive outcome—shared words or a broadly related topic are not enough. Apple then explains Supported, Contradicted, Mixed, or Unresolved on device, with citations, evidence limitations, and confidence rationale. On Apple-unavailable devices, the Public evidence scan leaves relevance-gated references Unresolved rather than treating overlap as proof.

For current live-web evidence, expand Live-web Fact-check evidence · Optional in Settings, enter an OpenAI model and Platform API key, save the key, then accept the disclosure. While Apple Intelligence is available, OpenAI receives only the clean grounded claim and bounded research words, returns cited evidence, and Apple remains the final reasoner. Only on an Apple-unavailable device can the same approval run a complete OpenAI Fact-check using the separately disclosed source material. OpenAI bills API usage separately; a ChatGPT subscription cannot be used instead. The app stores the key in Apple Keychain and sets store: false.

Unresolved means the selected method did not establish a supported, contradicted, or mixed result. It does not prove the claim false. Every option is an automated research aid—not exhaustive research or professional verification—so open the links and consult relevant primary or specialist sources before an important decision.

Use a custom model endpoint only when you intend to

The Advanced settings accept an OpenAI-compatible web address, model name, and optional API token. Remote services must use HTTPS; plain HTTP is accepted only for localhost or a private local-network server. Login details and extra URL parameters do not belong in the address. The separate token is sent only to the service you chose; changing that address clears the token and asks for consent again. Enabling this option replaces automatic Apple and Standard processing for Concept, Summary, Analysis, and Copy. Fact-check remains Apple-first; optional OpenAI live-web evidence is approved separately.

  • The full acquired title, URL, source text, and processing instructions go to the configured endpoint.
  • The token is stored in Apple Keychain and is not included in a library export.
  • A ChatGPT subscription is not an API key and cannot be connected as an account.
  • A local server such as Ollama can keep the model running on hardware you control.
  • For a remote provider, paste its HTTPS base URL and put its bearer token only in the separate API token field.
  • On a physical iPhone, localhost means the iPhone—not your Mac. A Mac-hosted endpoint requires an intentionally exposed and secured network address.

If the endpoint reports an error, What Holds shows it rather than silently sending the source somewhere else. Disable the override to return to automatic private processing.

For Apple App Review

No demo account, login, subscription, API token, or external model is required to exercise the core product. On Simulator and devices where Apple Intelligence is unavailable, standard built-in processing is expected.

  1. Choose Start learning on first launch.
  2. Create a Text capture with at least eight words, choose Summary, then choose Understand under Future use.
  3. Optionally write a quick prediction, process and save, then open the note in Library to see its learning plan, where the source came from, and how the note was made; choose View acquired source to confirm the exact stored text.
  4. Open Review, choose a confidence level, reveal the seeded due card, and compare the attempt.
  5. Open Ask and search the local library; every result links back to its supporting note.

Fresh installs use Automatic Fact-check. On Simulator, the visibly labelled Public evidence scan retrieves bounded public reference and scholarly evidence but leaves it Unresolved without a language model. On an eligible device, Apple Intelligence selects material source-grounded claims and reasons over relevance-gated excerpts on device. No key is required. OpenAI live-web evidence and custom models are optional and are not needed for review.
